# PyByY Launcher Hub
a minecraft bedrock ,java , and fornite luancher or
A simple launcher hub that uses Prism Launcher and PowerShell to open games you already own.

This project does not replace official launchers and does not bypass authentication or DRM.

---

## Features
- Launch Minecraft Java Edition using Prism Launcher
- Open Fortnite using the Epic Games Launcher
- Lightweight and simple
- Open-source and transparent

---

## How It Works
- Minecraft is launched through Prism Launcher
- Fortnite is opened via PowerShell, which starts the Epic Games Launcher
- No game files are modified
- No accounts or passwords are collected

---

## Requirements
- Windows 10 or Windows 11
- Prism Launcher installed
- Epic Games Launcher installed
- Legitimate ownership of the games

---

## Security & Safety
- This project is not malware
- All scripts are plain-text and open-source
- No DRM bypassing or pirated content
- Antivirus warnings may occur due to PowerShell usage (false positives)

## Usage
1. Install Prism Launcher and Epic Games Launcher
2. Download or clone this repository
3. Run the PowerShell script
4. Choose the game you want to launch
